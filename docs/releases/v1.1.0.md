First public release of JetBrains Privacy Guard, a local Java startup agent for selected telemetry and environment-inspection paths in JetBrains IDE plugins.

### Included

- In-memory rules for the inspected versions of Extra Icons, Extra ToolWindow Colorful Icons, Rainbow Brackets, Material Theme UI, GitHub Copilot, JetBrains AI Assistant and Junie.
- Direct plugin JVM-argument redaction and a filter for known Copilot telemetry hosts, while keeping AI features enabled.
- Reversible installer with dry run, offline verification, status, disable and rollback.
- Dependency-free build, synthetic JVM fixtures, installer tests and English/Russian documentation.
- MIT license.

### Requirements and validation

JDK 25 and Python 3.11+ are required to build from source. The included JAR requires Java 25 in the IDE. The real-IDE baseline is WebStorm 2026.2.3 on macOS Apple Silicon; other environments need their own verification.

The 19-test suite passed locally, including from a clean extraction of the distribution. Offline verification passed for 236 transformed classes in the installed plugin snapshot and six classes in the original Extra plugin archives. Tests use synthetic fixtures and do not redistribute vendor binaries.

The agent targets known mechanisms. AI requests still send the context needed to operate; a successful preflight is not a guarantee against new independent telemetry paths. See [compatibility](https://github.com/perkthefox/jetbrains-privacy-guard/blob/v1.1.0/docs/compatibility.md) for the precise scope.

### Download

The ZIP includes source, documentation, tests and `build/privacy-guard.jar`. The accompanying `.sha256` file checks archive integrity. Follow the [installation and recovery guide](https://github.com/perkthefox/jetbrains-privacy-guard/blob/v1.1.0/docs/installation.md).
